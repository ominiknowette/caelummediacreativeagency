# Caelum Media pre-launch audit — 23 October 2026

**Verdict: Not ready for launch.** The site builds and its available local flows work, but online enquiry delivery is unconfigured, final domain/indexing and privacy decisions are pending, and the About video's caption requirement needs review. This audit did not deploy or publish the site.

## Scope and environment

- Audited the original Next.js 14 implementation and upgraded it to the patched Next.js 15.5.28 release. The production build was served locally at `http://127.0.0.1:3100` in the ChatGPT in-app browser. No Safari, other browser engine, or real device was available. Viewports: 360, 390, 768, 1024 and 1440px, each at 900px height; core routes were rechecked at 390 and 1440px after the upgrade.
- Inspected source/configuration, the rendered pages, response headers and status codes, local assets, and a bounded synthetic enquiry flow. Used browser accessibility tree and a **temporary local axe-core scan of server-rendered page markup**. That static scan does not cover hydrated interactions; those were checked manually. The temporary audit page and script were removed, and `/audit.html` returns 404.
- Routes reviewed: `/`, `/about`, `/portfolio`, all 11 generated `/portfolio/[slug]` destinations through link/status inventory (the Instagram Reel detail was tested interactively), `/contact`, `/links`, `/services`, both package pages, `/growth-marketing`, `/brand-strategy`, `/privacy`, `/robots.txt`, `/api/enquiry`, and an unknown route.
- Shared implementation: `src/components/site.tsx` (shell, header/footer, cards, FAQ), `contact-form.tsx`, `media-track.tsx`, `about-content-video.tsx`, `evidence-gallery.tsx`, `service-tabs.tsx`, `decorative-pattern.tsx`. Brand/prices/contact/live carousel data are in `src/data/caelum.ts`; results and source relationships are in `src/data/results.ts`; the video switch is in `src/data/about-video.ts`.
- No active database, storage, authentication, payment, analytics tracker, third-party embed or administration route was found. The only server integration is the `/api/enquiry` server-side webhook. No `.env.local` was present. `CAELUM_ENQUIRY_WEBHOOK_URL` is unset in the final preview; `CAELUM_PUBLIC_SITE_URL` is also unset. Hosting provider and final domain are not configured in this checkout.

## Findings, fixes and retests

| Severity | Finding | Action and result | Status |
| --- | --- | --- | --- |
| High | Browser form submissions failed despite a working mock destination: Next.js' request URL hostname differed from the browser's Host header. | Validated the `Origin` hostname against the incoming Host header. A browser submission to the localhost mock then showed success only after `{ "received": true }`. | PASS |
| High | Previous backend validation accepted arbitrary service/package combinations, had no useful body cap or rate limit, and the client trusted any 2xx as success. | Added server checks for allowed service/package pairs, whitespace, types, lengths, JSON size/content type, origin, honeypot, timeout, and a bounded per-process rate guard. Client now requires the receipt flag. Invalid combination/blank name/oversize/foreign origin returned 400/400/413/403; sixth synthetic request returned 429. | PASS locally |
| Medium | Two small blue labels failed WCAG contrast on pale surfaces (axe measured 4.20:1 and 4.05:1). | Darkened only those labels to `#066A8A`; both routes passed the same automated recheck. | PASS |
| Medium | No favicon or usable final-domain social image metadata. | Pointed favicon at the supplied logo, and made the logo a provisional Open Graph image only when `CAELUM_PUBLIC_SITE_URL` is known. Build no longer emits a localhost social-image URL. Final image/domain remain launch decisions. | PASS for code; BLOCKED for final metadata |
| Medium | The local form rate guard is process-scoped and uses a request IP header; it is not sufficient for multi-instance public hosting. | Documented need for a shared hosting-edge limiter before launch. | BLOCKED |
| Critical | `npm audit` found a critical advisory in Next.js 14.2.18, including a [Windows-hosted remote-code-execution issue](https://github.com/advisories/GHSA-p293-qw3h-jr36); seven more package findings were reported. | Upgraded to the [patched Next.js 15.5.28 line](https://github.com/advisories/GHSA-2464-fhr4-w9xw) with matching lint config, migrated async route params, applied nonbreaking transitive fixes and a PostCSS 8.5.23 override. React 18 remained within the published peer range. Production build passed; final `npm audit` reports **zero vulnerabilities**. | PASS |
| Medium | The supplied About video has an audio toggle but no caption track. Automated audit cannot determine whether the audio contains speech or meaningful sound. | Kept the actual supplied video and controls. Client/content review must establish whether captions are needed and supply them if so. | BLOCKED |
| Low | Several unused public analytics copies exist alongside original evidence files. | Left the evidence files untouched. The attempted deletion was rejected by automatic approval review because preserving source/evidence assets was considered more important than this cleanup. | BLOCKED |
